# 속리산면 V23 영상 파이프라인 준비 상태

## 현재 사용 가능

- 지역 공용 디지털 트윈: `runtime_assets/v23/regions/sokrisan/sokrisan_region_digital_twin_base_v23.mp4`
- 선택 기준: 이벤트 `address`에 `충청북도`, `보은군`, `속리산면`이 모두 포함될 때
- 적용 범위: 속리산면에 등록된 모든 가입자의 V23 이벤트
- 원본 규격: 1280×720, 1,104프레임, 24fps, 약 46초
- 60초 타임라인 정책: 마지막 프레임을 60초까지 유지
- 최종 파일명: 실제 `source_farmland_id` 사용
- 대본 안전장치: 오송 필지명, 오송 중첩률, 오송읍복지회관 사용 금지

## 아직 누락된 실제 필지별 데이터

아래 항목이 없으므로 현재 속리산면 결과는 **지역 공용 디지털 트윈 + 가입자별 기상·수위 대본**이다. 필지 경계를 화면에서 정확히 강조하거나 필지별 위험 수치를 말하는 완전한 개인화 결과는 아니다.

1. Spring 트리거에서 team-flood로 전달되는 실제 필지 스냅샷
   - 필지 표시명, 주소, 중심 좌표, 면적, `boundaryGeoJson`, PNU
2. 속리산면 실제 필지 경계에 대응하는 영상 오버레이 또는 투영 좌표
3. 필지와 공인 홍수위험도/침수예상도 레이어의 교차 면적·비율 및 출처 버전
4. 속리산면 재해구호시설의 시설명, 좌표, 필지별 거리, 최신 개방 상태
5. 원본 영상의 장면별 타임코드 계약
   - 범람 전, 필지 확대, 침수 표현, 대피 정보가 시작·끝나는 정확한 프레임

## 남아 있는 임시 어댑터

Spring의 `FloodVideoWorkflowClient`는 속리산면 요청에도 내부 검증용으로 `OSONG-FIELD-DEMO-001`과 `USER-DEMO-001`을 전달한다. 현재 대본과 영상 선택에서는 실제 주소·실제 `source_farmland_id`를 우선하여 사용자 화면에 오송 정보가 나오지 않도록 차단했다.

다만 완전한 제거를 위해서는 V23 이벤트 계약에 `field_context`를 추가하고, 정적 `FieldRegistry` 대신 요청 시점 필지 스냅샷을 검증하는 구조로 전환해야 한다. 이 전환 전까지 내부 manifest의 `field_id`는 시각 프로필 ID이며 실제 가입 필지 ID가 아니다.

# 재난안내 슬라이드 고정 양식

`references/`의 PNG 3개는 영상 합성용 정보 슬라이드의 **로컬 원본 디자인 기준 데이터**다.

- `01_before_rain.png`: 비 오기 전 / 초록 / 1/3
- `02_during_rain.png`: 비 오는 중 / 주황 / 2/3
- `03_after_rain.png`: 비 그친 후 / 파랑 / 3/3

세 페이지는 항상 `비 오기 전 → 비 오는 중 → 비 그친 후` 순서로 모두 사용한다. Agent는 화면비, 배경색, 강조색, 여백, 배지, 페이지 번호, 번호 원형, 글자 위계, 하단 배너 및 면책 문구를 유지한다. 변경 가능한 항목은 제목, 설명, 정확히 세 개의 행동 문구, 행동 의미에 맞는 아이콘, 하단 핵심 문구뿐이다. 실제 영상 출력은 1280×720이며 첨부 원본의 1279×719 구도를 같은 상대 좌표로 재현한다.
